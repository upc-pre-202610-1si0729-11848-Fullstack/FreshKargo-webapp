# FreshKargo Landing Architecture

La Landing Page se organiza mediante una estructura modular por capas. La carpeta `landing` contiene las partes específicas del modelo de negocio FreshKargo, mientras que `shared` contiene piezas reutilizables como header, footer y selector de idioma.

Cada sección se encuentra separada en tres archivos: HTML para estructura, CSS para presentación y JavaScript para lógica de renderizado o eventos. Esta separación permite que diferentes integrantes del equipo trabajen en secciones distintas del landing.
